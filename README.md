# Бот для случайного выбора участника группы

Бот на aiogram 3 хранит участников каждой группы отдельно в SQLite через асинхронный SQLAlchemy.

Код разделён по слоям: `src/handler/` обрабатывает команды, кнопки и события Telegram; `src/service/` выполняет операции с участниками; `src/repository/` содержит запросы к базе. `src/main.py` запускает бота и подключает обработчики.

## Запуск

1. Установите зависимости: `uv sync`.
2. Создайте `.env` с `BOT_TOKEN=...` (см. `.env.template`). По умолчанию база находится в `bot.sqlite3` в рабочей папке. Путь можно изменить через `DATABASE_URL`, например `sqlite+aiosqlite:///./data/bot.sqlite3`.
3. Запустите бота: `uv run python src/main.py`. При запуске SQLAlchemy создаст таблицы, если их ещё нет.
4. Добавьте бота в группу и назначьте администратором, чтобы он получал события изменения состава группы. Для учёта сообщений уже присутствующих участников отключите Privacy Mode в BotFather и снова добавьте бота в группу.

Команды в группе: `/random` выбирает случайного участника, `/exclude` исключает себя, `/include` возвращает себя. Любой участник может ответить на сообщение другого командой `/exclude` или `/include` и изменить его участие. Исключение сохраняется после новых сообщений и повторного вступления.

## Панель управления

Любой участник группы открывает `/admin` и выбирает кнопку:

- **Список** — показывает записи этой группы, их ID и состояние.
- **Добавить** — принимает строку `ID | Имя | @username`. Вместо username можно указать `-`. Бот проверяет, что человек состоит в группе.
- **Обновить** — принимает такую же строку и меняет имя и username существующей записи. Значение `-` удаляет username. Ручные изменения сохраняются при следующих сообщениях участника.
- **Удалить** — принимает ID и запрашивает подтверждение. Если удалённый участник позже напишет сообщение или заново войдёт в группу, бот добавит его снова. Для постоянного исключения из выбора используйте `/exclude`.

Пошаговый ввод можно отменить командой `/cancel`. Записи других групп недоступны.

## Docker

Создайте `.env` с токеном и запустите `docker compose up --build -d`. При запуске бот создаёт отсутствующие таблицы через SQLAlchemy. SQLite хранится в именованном томе `bot_data`, поэтому данные сохраняются при пересоздании контейнера. Для просмотра логов: `docker compose logs -f bot`.

Telegram Bot API не предоставляет боту полный список участников группы. Бот запоминает тех, кого увидел в событиях вступления или сообщениях после его добавления. Ушедшие участники перестают участвовать в выборе. Боты не добавляются в список.
