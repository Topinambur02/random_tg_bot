# Бот для случайного выбора участника группы

Бот на aiogram 3 хранит участников каждой группы отдельно в SQLite через асинхронный SQLAlchemy.

Код разделён по слоям: `src/handler/` обрабатывает команды, кнопки и события Telegram; `src/service/` выполняет операции с участниками; `src/repository/` содержит запросы к базе. `src/main.py` запускает бота и подключает обработчики.

## Запуск

1. Установите зависимости: `uv sync`.
2. Создайте `.env` с `BOT_TOKEN=...` (см. `.env.template`). По умолчанию база находится в `bot.sqlite3` в рабочей папке. Путь можно изменить через `DATABASE_URL`, например `sqlite+aiosqlite:///./data/bot.sqlite3`.
3. Запустите бота: `uv run python src/main.py`. При запуске SQLAlchemy создаст таблицы, если их ещё нет.
4. Добавьте бота в группу и назначьте администратором, чтобы он получал события изменения состава группы. Для учёта сообщений уже присутствующих участников отключите Privacy Mode в BotFather и снова добавьте бота в группу.

Команды в группе: `/random` выбирает случайного участника. Любой участник может написать `/exclude @username` или `/include @username`, чтобы исключить или вернуть человека с указанным Telegram username. Регистр букв не важен. Username виден в `/admin` → «Участники». Команды также работают ответом на сообщение другого участника; без username и ответа меняют участие отправителя. Исключение сохраняется после новых сообщений и повторного вступления.

## Панель управления

Любой участник группы открывает `/admin`. Бот отправляет панель один раз и затем редактирует это же сообщение при нажатии кнопок. Повторный вызов `/admin` возвращает открытую панель в главное меню.

- **Участники** — показывает записи группы. Нажмите на имя, чтобы открыть карточку участника.
- **Исключить из выбора / Вернуть в выбор** — кнопка в карточке сразу меняет участие человека в случайном выборе.
- **Изменить** — кнопка в карточке запрашивает новое имя или `Новое имя | @новый_username`.
- **Удалить** — кнопка в карточке запрашивает подтверждение. Если удалённый участник позже напишет сообщение или заново войдёт в группу, бот добавит его снова. Для постоянного исключения из выбора используйте кнопку «Исключить из выбора».
- **Добавить участника** — кнопка в главном меню запрашивает `@username` уже известного боту участника. Если бот его ещё не знает, ответьте на сообщение этого человека строкой `@username`. Бот проверит его текущее членство в группе. По одному username Telegram Bot API не позволяет получить ID неизвестного человека.

Ввод имени и username остаётся текстовым. В остальном панель управляется кнопками; для отмены ввода нажмите «Назад» или отправьте `/cancel`. Записи других групп недоступны.

Обычные имена могут совпадать, поэтому для поиска используется уникальный Telegram `@username`. Если у человека нет username, команды `/exclude` и `/include` можно отправить ответом на его сообщение.

## Docker

Создайте `.env` с токеном и запустите `docker compose up --build -d`. При запуске бот создаёт отсутствующие таблицы через SQLAlchemy. SQLite хранится в именованном томе `bot_data`, поэтому данные сохраняются при пересоздании контейнера. Для просмотра логов: `docker compose logs -f bot`.

Когда бота добавляют в группу, он сразу записывает в базу пригласившего участника и администраторов группы. Затем он автоматически запоминает остальных по событиям вступления и сообщениям. Telegram Bot API не предоставляет полный список людей, которые уже состояли в группе до добавления бота, поэтому записать всех таких участников сразу нельзя. Для получения событий об обычных участниках бот должен быть администратором группы; для учёта их сообщений отключите Privacy Mode. Ушедшие участники перестают участвовать в выборе. Боты не добавляются в список.
